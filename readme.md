Aplicativo de automação para processamento de notas fiscais, capaz de manipular PDFs e XMLs de compras e serviços, realizar download automático dos arquivos, extrair informações estruturadas e gerar planilhas a partir dos dados presentes nos XMLs.

🚀 Automação de Processamento de Notas Fiscais (PDF e XML)

🔹 Funcionalidades principais:

• Download automático de PDFs e XMLs de notas fiscais de compra e serviço.

• Extração e organização de informações do XML em planilhas automatizadas.

• Renomeação e classificação de PDFs para facilitar o gerenciamento.

• Tratamento de erros e pendências, com logs claros de arquivos processados e pendentes.

• Controle de execução via atalhos de teclado (F8 para parar, F9 para pausar/retomar).

🔹 Tecnologias utilizadas:

• Python: linguagem principal para automação e manipulação de arquivos.

• Selenium WebDriver: interação automatizada com navegadores e sites.

• PyAutoGUI e keyboard: automação de cliques, teclas e monitoramento do usuário.

• Chrome portátil + Buster: integração com navegador sem dependências locais.

• Threading: execução paralela para monitoramento de teclas e download.

• Manipulação de arquivos: organização automática de PDFs, XMLs e planilhas.
